コンウェイのライフゲーム / Conway's Game of Life

「生」と「死」の2状態、周囲8セル、同時更新。この小さな規則から、止まるもの・振動するもの・移動するものが生まれます。

Two states, alive and dead; eight neighbors; all cells update at once. From this tiny rule come patterns that stand still, patterns that oscillate, and patterns that travel.

まずは1世代ずつ見てみよう / Start one generation at a time

  1. パターン標本から「ブリンカー」を選び、「この配置で始める」を押します。 / Pick Blinker from the pattern gallery and press "Start from this pattern."
  2. 「1世代進める」を押すと、横一列の3セルが縦一列になります。もう一度押すと元に戻ります。 / Press "Step one generation": the horizontal row of three cells becomes a vertical row. Press again and it flips back.
  3. 「グライダー」を同じように試し、4世代後の形と位置を比べてください。 / Try the Glider the same way and compare its shape and position after four generations.
  4. 「すべて消す」で空にし、自分でセルを描いて再生してみましょう。 / Clear the board, draw your own cells, and press Play.

標準ルール：B3/S23 / The standard rule: B3/S23

各セルは上下左右と斜めの、周囲8セルの生存数を数えます。自分自身は数に含めません。

Each cell counts how many of its eight neighbors (up, down, left, right and the four diagonals) are alive. The cell itself is not counted.

死セル ＋ 生きた隣人3個 → 誕生（Birth）
生セル ＋ 生きた隣人2個または3個 → 生存（Survival）
それ以外 → 死セル
Dead cell + exactly 3 live neighbors → Birth
Live cell + 2 or 3 live neighbors → Survival
Anything else → dead

すべてのセルは、同じ世代の盤面を見て同時に更新されます。先に更新したセルの結果を、ほかのセルの判定へ混ぜません。

Every cell reads the same generation and updates simultaneously. A cell that has already been updated never feeds into another cell's decision in the same step.

このルールを短く書いたのが B3/S23 です。変化の途中に乱数は使いません。同じ配置・ルール・境界条件なら、同じ経過を再現できます。

B3/S23 is the short notation for this rule. No randomness is used during the evolution: the same starting pattern, rule and boundary condition always give the same history.

パターン標本 / Pattern gallery

  • ブロック / Block：形が変わらない静止物体。 / A still life; its shape never changes.
  • ブリンカー・ヒキガエル・ビーコン / Blinker, Toad, Beacon：2世代で形が戻る振動子。 / Oscillators that return to their shape every 2 generations.
  • パルサー / Pulsar：対称的な形が3世代で戻る振動子。 / A symmetric oscillator that repeats every 3 generations.
  • グライダー / Glider：形を変えながら、4世代で斜めに1セル移動するパターン。 / Changes shape as it moves one cell diagonally every 4 generations.
  • 軽量宇宙船 / Lightweight spaceship：4世代で横に2セル移動するパターン。 / Moves two cells sideways every 4 generations.
  • Rペントミノ / R-pentomino：5セルから始まり、多くの世代にわたって複雑に変化する配置。 / Starts from just five cells and evolves in complicated ways for many generations.
  • ゴスパーのグライダー銃 / Gosper glider gun：30世代ごとにグライダーを放出する配置。 / Emits a new glider every 30 generations.

これらは標準ルールで、ほかの物体や端との干渉がないときの性質です。ルールを変えたり、別のパターンを重ねたりすると、同じ挙動になるとは限りません。

These properties hold under the standard rule when nothing else interferes, including the edges of the board. Change the rule or overlay other patterns, and the behavior may differ.

操作と実験の戻し方 / Controls and resetting an experiment

  • 描く／消す / Draw and erase：クリック・タップ・ドラッグで1セルずつ編集します。編集すると停止し、世代数を0に戻します。 / Click, tap or drag to edit cells. Editing pauses playback and resets the generation count to 0.
  • スタンプ / Stamp：選択中のパターンを追加します。「回転」で向きを変えられます。端付近ではパターンが盤面内に収まる位置へ寄せます。 / Adds the selected pattern; "Rotate" changes its orientation. Near the edge, the pattern is shifted so that it fits on the board.
  • キーボード / Keyboard：盤面にフォーカスし、矢印キーで位置を選び、Enterで描画・スタンプ、Deleteで消去できます。 / Focus the board, move with the arrow keys, press Enter to draw or stamp, and Delete to erase.
  • この配置で始める / Start from this pattern：選択中のパターンで盤面を置き換え、停止します。現在のルールは維持します。 / Replaces the board with the selected pattern and pauses. The current rule is kept.
  • 開始時に戻す / Return to start：直前の実験の開始配置へ戻ります。編集後に再生・1世代実行した場合は、その編集後の配置が開始配置です。ルールや境界を変更した場合は、変更時の配置から新しい実験になります。 / Goes back to the starting pattern of the current experiment. If you edited and then played or stepped, the edited pattern is the new start. Changing the rule or the boundary begins a new experiment from the current pattern.
  • ランダムに配置 / Randomize：指定した生存率を確率として、盤面を新しく作ります。実際の生存率は試行ごとに少し変わります。 / Builds a new board using the chosen density as a probability. The actual density varies slightly from run to run.
  • 軌跡 / Trails：最近消えたセルを薄く表示します。軌跡は見た目だけで、生死の計算には入りません。 / Faintly shows recently dead cells. Trails are visual only and do not affect the calculation.
  • スマートフォン / Mobile：歯車で設定を開閉します。初期盤面は描きやすい48×36。標準・広い盤面にも切り替えられます。 / Use the gear icon to open or close settings. The default board is an easy-to-draw 48×36; standard and wide boards are also available.
  • PNG保存 / Save PNG：その時点の盤面を保存します。格子と軌跡は表示設定に従います。 / Saves the current board. Grid and trails follow the display settings.

端はどうなっている？ / What happens at the edges?

「上下・左右の端をつなぐ」がONなら、右端の隣は左端、下端の隣は上端です。盤面がドーナツ状につながっているものとして計算します。OFFなら盤面の外は常に死セルとして扱います。

With "Wrap edges" on, the neighbor of the right edge is the left edge and the neighbor of the bottom edge is the top edge, so the board behaves like a torus (a donut). With it off, everything outside the board is treated as permanently dead.

このアプリは有限の盤面です。無限平面のライフゲームとは境界条件が違います。特にグライダー銃では、端を回って戻ったグライダーが銃に衝突し、壊すことがあります。長く観察するには盤面を広げたり、端の接続をOFFにしたりして比較してください。

This app uses a finite board, so its boundary differs from the infinite plane of the original Game of Life. In particular, with a glider gun, gliders that wrap around the edge can crash back into the gun and destroy it. To observe for longer, enlarge the board or turn wrapping off and compare.

ルールを変える：Life-likeセルオートマトン / Changing the rule: life-like cellular automata

誕生Bと生存Sの数字を自由に選べます。「隣人が何個のとき生まれるか／生き残るか」を変えて、異なる世界を比べられます。

You can choose the numbers for Birth (B) and Survival (S): how many live neighbors cause a cell to be born or to survive. Changing them gives you very different worlds to compare.

  • Conway（B3/S23）：通常のライフゲーム。 / The ordinary Game of Life.
  • HighLife（B36/S23）：隣人6個でも誕生します。標準ルールと似ていますが、自己複製するパターンも知られています。 / Cells are also born with 6 neighbors. It resembles the standard rule, and a self-replicating pattern is known for it.
  • Seeds（B2/S）：隣人2個で誕生し、生セルは次の世代に必ず死にます。 / Cells are born with 2 neighbors, and every live cell dies in the next generation.
  • Day & Night（B3678/S34678）：生と死を反転した状況にも対応する対称性を持つルール。 / A rule with a symmetry that also holds when live and dead are swapped.

B0を選ぶと、隣人がいない死セルも誕生します。このアプリでは盤面全体の急な点滅を抑えるため、B0を含むルールの再生速度を最大2世代／秒に制限しています。

With B0, even dead cells with no live neighbors are born. To avoid sudden flashing of the whole board, this app limits playback of any rule containing B0 to at most 2 generations per second.

Leniaとのつながり / Connection to Lenia

ライフゲームでは状態が0か1、時間も1世代ずつです。図鑑のLeniaは連続値の状態と成長関数を使い、なめらかな生物のような形を扱います。「局所的な規則から全体の形が生まれる」という共通点を、両方のモデルで比べてみてください。

In the Game of Life, a cell's state is 0 or 1 and time advances one generation at a time. Lenia in this collection uses continuous-valued states and a growth function to produce smooth, creature-like forms. Both share the idea that "global form emerges from local rules," so try comparing them.
