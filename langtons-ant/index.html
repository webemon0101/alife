ラングトンのアリ

Langton’s Ant

右か左か、それだけのルールから複雑な軌跡と「高速道路」が生まれます。

初期状態 / Start

基本ルール RL の白紙から12,000歩を計算して、一時停止します。

ルール / Rules

R・Lを2〜12文字。適用すると盤面がリセットされます。
Enter 2–12 R/L characters; applying resets the board.

表示と速度 / View & Speed

操作 / Interaction

描画すると一時停止。色は状態1です。ホイールで拡大縮小。
Painting pauses the simulation and sets state 1. Scroll to zoom.

仕組み / How it works

今いるセルの色で90°回転 → 色を次へ → 1歩進む。基本のRLでは白で右、黒で左。表示は暗い背景と明るい軌跡で表現しています。
Turn, change the cell’s color, then move forward. The classic rule turns right on white, left on black.
