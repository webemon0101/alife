L-System（エルシステム）

植物の自己相似成長 / Self-similar plant growth

文字を書き換えて、枝を伸ばす。同じルールの繰り返しから植物のような形が生まれます。

モデル / Model

書き換え規則 / Rewriting rules

F・G: 線を引く / draw
f: 移動のみ / move
+: 左回転 / left · −: 右回転 / right
[: 位置と向きを保存 / save
]: 保存した位置に戻る / restore
Xなど: 書き換え用の文字 / placeholders

表示 / Appearance

ドラッグで移動、ホイールまたは下のスライダーで拡大。
Drag to pan; use the wheel or slider to zoom.

観察のヒント / Explore

世代を増やすと全ての文字が同時に書き換わります。「描画」は完成形を線の順番に表示するアニメーションです。実際の植物の成長時間を表すものではありません。
Each generation rewrites all symbols in parallel. “Draw” reveals the resulting lines in order; it does not model biological growth time.
