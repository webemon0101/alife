粒子レニア / Particle Lenia

粒子が作る場と、その場を変える粒子。

観察する / Explore

まず200粒子の雲を動かしてください。輪と2つの集団も初期配置から試せます。これらは本サイトの初期配置で、作者の発見個体を複製したものではありません。形の変化や持続する動きを観察しますが、特定の回転・分裂・自己複製は保証しません。シードとリセットで同じ初期条件に戻ります。粒子数変更とプリセット変更も初期化し、運動パラメーターを代表値に戻します。

Start with a 200-particle cloud, ring or two groups. These are starting layouts, not archived creatures. Reset restores the seed and reference parameters. Count and preset changes reset the simulation. Outcomes vary.

局所的な運動ルール / Local dynamics

2022年にAlexander Mordvintsev、Eyvind Niklasson、Ettore Randazzoが公開したモデルに基づきます。各粒子が作る環状カーネルを足した場Uに、好む密度を選ぶ関数Gを適用し、近距離の反発Rと組み合わせます。

K(r) = w exp(−((r−μK)/σK)²)
U(x) = Σ K(|x−pⱼ|)
G(U) = exp(−((U−μG)/σG)²)
R(x) = c/2 Σ max(1−|x−pⱼ|, 0)²
dpᵢ/dt = −∇[R−G](pᵢ)

他の粒子の位置を固定した局所空間勾配を計算します。慣性や粒子の増減はありません。系全体のエネルギーの勾配降下とは異なり、総エネルギーの単調減少を仮定しません。Uには自分のカーネル値も含め、重なった点の勾配を0としています。

Particles follow the local spatial gradient with source positions held fixed, without momentum. This is not gradient descent of total system energy. The density field includes each particle's own kernel value; the gradient at coincident positions is set to zero.

計算と表示 / Computation

代表値μK=4、σK=1、w=0.022、μG=0.6、σG=0.15、c=1、時間刻み0.1。境界のない2次元平面を陽的Euler法で同時更新します。CPUのWeb Workerで全粒子対を計算し、50〜800粒子に対応します。時間刻みを小さくすると数値誤差を調べられます。更新速度は実時間当たりのステップ数で、運動ルールを変えません。

全体が収まるよう表示を追従させています。画面の伸縮・移動はカメラの変化の場合があります。粒子半径と色は描画だけに影響します。色の違いは種類の違いではありません。重い場合は減速し、継続的な高負荷や応答停止時には最後に完了した状態で停止します。

CPU Web Worker, all-pairs local gradients, explicit Euler integration and an unbounded plane. Display auto-fits all particles; apparent scaling can be camera motion. Dot size and colors affect rendering only. Slow devices reduce the update rate or pause. Smaller time steps help assess numerical sensitivity.

保存と交換 / Snapshots

保存ボタンで位置・運動パラメーター・ステップ数をJSONに出力し、一時停止します。開くボタンまたはドロップで復元して再生できます。ファイルはサーバーに送信しません。Particle LifeのJSONや原作者の画像形式とは互換性がありません。端末間の丸め誤差で長期の軌道は変わる場合があります。

Save positions, parameters and step count as JSON; open or drop to restore paused. Files stay in your browser. This format is distinct from Particle Life JSON and the authors' image snapshots. Long-term trajectories can diverge across devices.
