ヴィツェック・モデル

Vicsek Model · Active Matter

集団運動 / Collective motion

整列度0：ばらばら、1：同じ方向。 / Order: 0 disordered, 1 aligned.

設定 / Settings

密度・粒子数変更は初期化。近隣半径1、境界はループ。 / Density and count changes reset. Radius 1; wrapped boundaries.

ノイズ走査 / Noise sweep

ノイズ1→0、11条件。各条件200ステップ待機＋200ステップ測定。 / 11 levels, 200 warm-up + 200 sample steps each.

各条件を同じシードのランダム配置から開始。単一試行の探索で、転移の確定ではありません。 / Same seeded start per level; exploratory single runs, not proof of a phase transition.

CPU / Web Worker。高負荷では減速・停止。スマホは粒子数を少なくしてください。 / Slows or pauses under heavy load.
