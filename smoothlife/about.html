SmoothLife / スムーズライフ

円と環で近隣を調べる、滑らかなライフゲーム。

まず観察する / Explore

斑点のスープから始め、膜や移動する塊の変化を観察してください。ドラッグで状態を加え、消去モードまたは右クリックで削れます。空白から自分で描くこともできます。初期配置は本サイトで生成したもので、既知のグライダーを収録したものではありません。分裂や生存を保証しません。

Start from random patches, a single patch or an empty canvas. Drag to paint; use Erase or right-click to remove. These are generated starting layouts, not archived gliders. Division and survival are not guaranteed.

ルール / Rule

Stephan Raflerが2011年に発表したSmoothLifeに基づきます。状態は0〜1。内側の円の平均mと外側の環の平均nを計算し、シグモイドで滑らかにした誕生・生存区間から次の状態sを決めます。内側半径は外側の1/3、円の縁を幅1格子の重みで平滑化しています。

σ(x,a,α) = 1 / [1 + exp(−4(x−a)/α)]
t = σ(m, 0.5, αm)
lo = b₁(1−t) + d₁t, hi = b₂(1−t) + d₂t
s = σ(n, lo, αn) · [1 − σ(n, hi, αn)]

離散時間では次の状態をsに置換します。連続時間近似ではf ← clamp(f + dt(2s−1), 0, 1)。両者は異なる挙動を示し、同じ設定でグライダーが維持されるとは限りません。代表ルールの区間値は原論文Fig. 1に基づきますが、初期の外側半径は軽量化のため15（図では21）です。

Discrete updates replace the state with s. Continuous approximation integrates 2s−1 with explicit Euler and clamps to [0,1]. These are different dynamics. Reference thresholds follow Fig. 1; our default outer radius is 15 rather than 21. Grid sampling approximates the continuous spatial model.

見方と限界 / Interpretation

密度は状態の平均で、独立した栄養場ではありません。分裂は同一個体の完全複製とは限らず、消滅や変形もあります。画面は格子を滑らかに表示しますが、実際の数値計算は有限格子上です。解像度を変えると、半径が格子単位のため世界内の相対的な構造サイズも変わります。境界は上下左右のループです。

Local density is not a separate nutrient field. Splitting does not imply exact self-replication. Computation uses a finite grid with periodic boundaries. Changing grid size resets the world and changes the relative scale of fixed-radius structures.

操作と負荷 / Controls and performance

リセットは現在のルールのままシードに基づく初期配置を復元します。「代表ルールに戻す」はルールも初期値に戻します。CPUのWeb Workerで計算し、高負荷では更新頻度を下げ、継続する場合や応答がない場合は停止します。別タブでは新たな計算を止めます。128格子から試してください。

Reset keeps the rule and restores the seeded layout. Reference rule restores default parameters too. CPU calculations run in a Web Worker; heavy work slows or pauses. Start with a 128 grid. Hidden tabs suspend new work.

保存と交換 / Snapshots

JSON保存で格子状態・ルール・時間方式・ステップ数を保存します。開くボタンまたはドロップで一時停止状態に復元。ファイルはサーバーに送信しません。他モデルのJSONとは互換性がありません。

Save and restore the grid, rule, update mode and step count as JSON. Import pauses playback. Files stay in the browser and are specific to this simulator.
