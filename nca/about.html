Neural Cellular Automata

NCA — 学習した細胞のルールから生まれる成長と自己修復

使い方 / Getting started

初期状態は中央の1つの種です。まず自己修復モデルで「200歩進める」を押し、形が育つのを待ってください。処理後は一時停止します。形の一部を指やマウスで削り、再生して修復を観察できます。

Start from a seed at the center. Choose Regenerating and advance 200 steps; the simulation pauses afterward. Erase part of the pattern, then press Play to observe recovery.

  • トカゲ・蝶・木と、3種類の学習方法を選べます。変更すると種から再開します。 / Choose lizard, butterfly or tree and one of three training regimes. Switching models resets to a seed.
  • 「種を置く」で別の場所にも種を置けます。複数の個体の衝突や境界付近では、期待する形にならない場合があります。 / Plant more seeds to explore interactions; collisions and boundaries can disrupt the learned shape.
  • 「すべて消す」で空の盤面にできます。残存細胞がなければ自動復活しません。 / Clear all removes the entire state; an empty board cannot regrow without a new seed.
  • スマートフォンの設定は⚙から開きます。PNGは現在の表示を保存します。 / Open mobile controls with ⚙. Save the current view as PNG.

学習方法を比較する / Compare training regimes

成長 / Growing：種から目標の形になるよう学習。完成後の維持は苦手な場合があります。
維持 / Persistent：成長した状態も使って学習し、形を保つことを促します。
自己修復 / Regenerating：学習時に損傷を加え、残った細胞からの回復を促します。

Growing models learn to reach a target. Persistent models are also trained on evolved states to support stability. Regenerating models additionally train on damaged states. These are different pretrained networks, not a visual effect applied to the same model.

局所的なニューラルネット / A local neural rule

各セルは色・不透明度と内部状態を持ち、近傍の情報から小さなニューラルネットで変化量を計算します。全てのセルが同じ学習済み規則を使います。目標画像は学習に使われていますが、実行中に画像を貼り戻して修復する仕組みではありません。

Each cell stores visible and hidden state. A shared neural network computes changes from local neighborhood information. The target image was used during training; runtime repair does not paste the target back onto the grid.

生物そのものの再現や、任意の傷から必ず復元する保証ではありません。大きな損傷、回転、複数の種など、学習条件から離れると崩壊する場合があります。 / Recovery is not guaranteed, especially under conditions unlike training.

このページの実装 / Implementation

原研究で公開された学習済み重みとWebGL実装を使い、96×96セルをブラウザ内で更新します。学習は行いません。重みと描画ライブラリはこのサイトから読み込み、実行にAI APIは使いません。端は反対側につながる方式です。内部状態表示は各チャンネルを並べたもので、生物学的な器官の表示ではありません。

This page runs the original pretrained, quantized models on a 96×96 grid with WebGL. It performs inference only, with no AI API calls. Model files and the rendering library are served locally by this site. Grid boundaries wrap. Internal-state view shows packed channels, not biological organs.

WebGL対応が必要です。速度は端末性能で変わり、非表示タブでは計算を停止します。動きを減らす設定が有効な端末では、一時停止状態で開始します。
