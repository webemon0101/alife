体と動かし方を一緒に進化させる。
Evolve a body and the way it moves.

EvoGymに着想を得た軽量版。独自の物理計算とGAを使用します。 / A lightweight adaptation with custom physics and a genetic algorithm.

進化 / Evolution

集団サイズの変更で初期化。体の進化・変異率は次の世代の子に適用。 / Population changes reset; mutation controls affect the next offspring.

体を描く / Body editor

辺でつながる4個以上のセルと、筋肉が1個以上必要です。選択・編集後にボタンで反映。 / At least four edge-connected cells and one muscle. Apply to restart.

成績 / Fitness history

水色：最優秀、灰：有効個体の平均。6秒間の右向き移動距離（1目盛り＝1ボクセル）。 / Best and valid mean; rightward travel in six seconds, in voxel units.

個体を交換 / Share a creature

JSONをドロップしても再現できます。体と脳を保存し、同じ開始姿勢から再生。全世代のバックアップではありません。 / Save body and brain, replay from the same start. Not a full evolution checkpoint.

比較再生 / Replay

6秒ごとに最新の最優秀個体へ更新。カメラは個体を追従。例の読み込みは現在の探索を置き換えます。 / The latest champion is picked every six seconds; following cameras. Loading the example replaces the current search.
